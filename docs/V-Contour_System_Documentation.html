🥧 Raspberry Pi 4 Installation

One-Command Setup: Get the V-Contour system running on your Raspberry Pi 4 in under 10 minutes.

Option 1: Automated Setup (Recommended)

🚀 Quick Install Script

Run this single command on a fresh Raspberry Pi OS installation:

# Download and run the setup script
curl -sSL https://raw.githubusercontent.com/morrisraybrooks/apps/main/scripts/pi4-setup.sh | bash

Or clone first and run locally:

git clone https://github.com/morrisraybrooks/apps.git
cd apps
chmod +x scripts/pi4-setup.sh
./scripts/pi4-setup.sh
The script will:
  • Enable SPI, I2C, and GPIO interfaces
  • Install Qt5, libgpiod, and build tools
  • Configure user permissions for GPIO access
  • Clone, build, and install the application
  • Create a launcher command (v-contour)
  • Set up optional auto-start service

Option 2: Manual Installation

Step 1: Update System & Install Dependencies

# Update package lists
sudo apt update && sudo apt upgrade -y

# Install build tools and Qt5
sudo apt install -y build-essential cmake git pkg-config \
    qtbase5-dev qtcharts5-dev libqt5charts5-dev

# Install GPIO library (modern libgpiod replaces deprecated wiringPi)
sudo apt install -y libgpiod-dev libgpiod2 gpiod

Step 2: Enable Hardware Interfaces

# Run Raspberry Pi configuration
sudo raspi-config

# Navigate to:
# → Interface Options → SPI → Enable
# → Interface Options → I2C → Enable
# → Interface Options → GPIO → Enable (if available)

# Reboot to apply changes
sudo reboot

Step 3: Clone and Build

# Clone the repository
git clone https://github.com/morrisraybrooks/apps.git
cd apps

# Create build directory and compile
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release -DRASPBERRY_PI_BUILD=ON
make -j3  # Use -j3 for Pi 4 (prevents memory exhaustion)

Step 4: Install System-Wide (Optional)

# Install to system directories
sudo make install
sudo ldconfig

# Now run from anywhere:
vacuum-controller-launcher

Step 5: Run the Application

# From build directory (development)
sudo ./VacuumController

# Or if installed system-wide
v-contour

# With Wayland display (recommended for 50" displays)
QT_QPA_PLATFORM=wayland QT_SCALE_FACTOR=1.5 ./VacuumController

Troubleshooting

Common Issues:
  • "Permission denied" on GPIO: Run with sudo or add user to gpio group: sudo usermod -aG gpio $USER
  • "libgpiod not found": Install with sudo apt install libgpiod-dev
  • "SPI device not found": Enable SPI via sudo raspi-config and reboot
  • "Qt not found": Install Qt5 dev packages: sudo apt install qtbase5-dev qtcharts5-dev

Analog-to-Digital Conversion: MCP3008 ADC

🔌 8-Channel 10-bit ADC with SPI Interface

The MCP3008 converts analog pressure sensor voltages (0-5V) to digital values (0-1023) for processing by the Raspberry Pi. It communicates via SPI at up to 3.6 MHz, enabling fast multi-channel sampling.

💡 ADC Operation
The MCP3008 uses Successive Approximation Register (SAR) architecture for fast, accurate conversion. Each pressure sensor outputs 0-5V proportional to 0-75 mmHg (0-10 kPa). The ADC converts this to a 10-bit value (0-1023), providing ~0.073 mmHg resolution. The Raspberry Pi reads all three channels sequentially via SPI in under 1ms, enabling the 10Hz control loop to maintain real-time responsiveness.

💡 Signal Chain Performance
  • End-to-End Latency: <2 ms from physical pressure change to software value
  • Resolution: ~0.073 mmHg per ADC bit (75 mmHg / 1024 levels)
  • Accuracy: ±1 mmHg typical, ±2 mmHg maximum (including sensor, ADC, and calibration errors)
  • Noise Floor: <0.5 mmHg RMS with filtering
  • Bandwidth: DC to 50 Hz (sufficient for physiological signals)
  • Update Rate: 10 Hz (100 ms) for control loop, but sensors sampled at 1 kHz internally
  • Dynamic Range: 0-75 mmHg (0-10 kPa) vacuum pressure

🧠 5. Orgasm Control Algorithm

The control algorithm combines advanced signal processing techniques including:

ℹ️ Sensor Fusion Details
The arousal estimation system fuses multiple physiological signals using a weighted combination algorithm. When heart rate monitoring is enabled, pressure sensors contribute 70% and HR features 30%. The final value is smoothed with an exponential moving average (α=0.15) to reduce sensor noise while maintaining responsiveness.

4. Anti-Detachment System (Adaptive Seal Leak Detection)

🛡️ Intelligent Seal Integrity Monitoring

The Anti-Detachment System is a critical safety and performance feature that continuously monitors the vacuum seal between the cup and the body. It must distinguish between genuine seal failures (requiring immediate action) and normal physiological changes (tissue swelling during arousal) that naturally affect pressure readings.

Implementation Logic
⚠️ Why Adaptive Thresholds Are Critical
During arousal, tissue swelling (engorgement) reduces the effective chamber volume, which naturally increases pressure readings. A fixed threshold would trigger false positives during normal arousal progression, incorrectly detecting "leaks" when the seal is actually intact. The adaptive threshold compensates by lowering the leak detection threshold as arousal increases, accounting for the expected pressure changes from physiological engorgement.
💡 Physiological Compensation
  • Low Arousal (0.0-0.3): Threshold = 100% of baseline (no compensation needed)
  • Medium Arousal (0.3-0.7): Threshold = 70-85% of baseline (moderate swelling expected)
  • High Arousal (0.7-1.0): Threshold = 50-70% of baseline (significant engorgement)
  • Clitoral Pressure Cross-check: If clitoral pressure is rising, gradual leak detection is suppressed (indicates normal engorgement, not leak)

What is TENS?

TENS is a non-invasive neuromodulation technique that delivers controlled electrical pulses through skin-surface electrodes to stimulate nerves. Originally developed for pain management, TENS has emerged as a validated therapeutic approach for enhancing female sexual arousal through dorsal genital nerve stimulation (DGNS).

How It Works for Sexual Stimulation

  1. Activates afferent sensory fibers → Enhanced genital sensation
  2. Triggers sacral reflex arc (S2-S4) → Autonomic arousal response
  3. Increases genital blood flow → Engorgement and lubrication
  4. Modulates pudendal motor neurons → Pelvic floor activation

The dorsal genital nerve is the primary sensory pathway for clitoral sensation and orgasm. Electrical stimulation at validated parameters (20 Hz, 400 μs) significantly improves Female Sexual Function Index (FSFI) scores in clinical studies.
