The GameEngine manages the complete game lifecycle from loading through results processing.

Game State Machine

Game Lifecycle Flow

  1. Load Game: loadGame(gameId) - Load game definition from JSON
  2. Initialize: Configure stimulation parameters, connect sensors
  3. Countdown: 3-2-1 countdown before stimulation begins
  4. Running: Active gameplay with real-time objective tracking
  5. Evaluation: Every 100ms: check objectives, fail conditions, update score
  6. End Game: Victory, failure, timeout, or safeword triggers end
  7. Consequences: Apply reward or punishment based on result

Timing Calculation

// Period in microseconds
m_periodUs = 1,000,000 / m_frequencyHz;  // 50,000 μs at 20 Hz

// For biphasic symmetric: equal positive and negative phases
m_positiveDurationUs = m_pulseWidthUs;   // 400 μs
m_negativeDurationUs = m_pulseWidthUs;   // 400 μs

// Inter-pulse gap is the remainder of the period
m_interPulseUs = m_periodUs - m_positiveDurationUs - m_negativeDurationUs;
// = 50,000 - 400 - 400 = 49,200 μs

7.6 Safety Systems

⚠️ Critical TENS Safety
TENS involves electrical current through sensitive tissue. All safety systems are hardware-enforced and cannot be bypassed by software.

  • Impedance monitoring during operation (1-10 kΩ valid range)

  • Automatic shutdown on fault detection
  • Amplitude ramping for comfort (500ms soft start/stop)

Hardware Safety Features

  1. Galvanic Isolation: 1500V isolation between Pi and output stage
  2. Current Limiting: Hardware current limit at 85 mA (fuse-backed)
  3. Charge Balance: Biphasic waveform ensures zero net DC current
  4. Soft Start: Amplitude ramps from 0 to target over 500ms
  5. Auto-Shutoff: If no control signal for 2 seconds, output disables
  6. Opto-Isolation: IL716 optocoupler isolates control signals

Software Safety Checks

bool TENSController::canEnable() const {
    // Check emergency stop
    if (m_hardware->isEmergencyStop()) return false;

    // Check vacuum seal integrity (clitoral cup must be sealed)
    double clitoralPressure = m_hardware->readClitoralPressure();
    if (clitoralPressure < MIN_SEAL_PRESSURE_MMHG) return false;  // 10 mmHg

    // Check electrode impedance (if measurable)
    if (m_electrodeImpedance > MAX_IMPEDANCE_OHMS) return false;  // 10kΩ

    // Check driver fault status
    if (m_faultDetected) return false;

    // Check user consent
    if (!m_consentManager->hasTENSConsent()) return false;

    return true;
}
